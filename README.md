## 🏛️ Ключевой функционал обновления

1. **Бесконечный Комбинаторный Генератор (0 токенов расхода):**
   * Работает полностью локально и мгновенно, не расходует API токены.
   * Огромная база разнообразных абсурдных стартапов по 5 направлениям:
     * **Кухня & Гастрономия:** умные кастрюли для пельменей, лазерная проверка шаурмы, сомелье доширака, дозаторы майонеза.
     * **Офис & Карьера:** симуляторы работы, генераторы отмазок, анти-зум двойники.
     * **Быт & Дом:** RFID-поисковики вторых носков, прессовщики пакетов с пакетами, радио-пульты от ТВ.
     * **Двор & Город:** скамейки с бабушками-валидаторами, автономные дроны-будильники.
     * **Отношения & Жизнь:** краткосрочная аренда котов для сторис, служба профессиональных извинений.
   * Система защиты от повторов: никогда не выдает одно и то же подряд!

2. **100% Русскоязычный и Детальный Интерфейс:**
   * Все термины, метрики, SWOT, дорожные карты и описания переведены и выверены на чистом русском деловом языке.
   * **KPI Метрики:** Объем Рынка (TAM), Ежемесячные Траты (Burn Rate), Запас Прочности (Runway), Юнит-Экономика, Индекс Хайпа.
   * **SWOT-Матрица 2x2:** Сильные стороны, Слабые места, Возможности, Угрозы.
   * **Дорожная Карта (Q1-Q4):** Реалистичные квартальные этапы развития.
   * **Команда Фаундеров:** 3 ключевых лица со смешными биографиями.
   * **Интерактивный ROI-Калькулятор:** Ползунок депозита с расчетом прибыли и натуральных дивидендов (пельмени, котики, шаурма).

3. **Полноценная Реляционная База Данных Синдиката:**
   * Модуль `database.js` с хранением в `LocalStorage` / `IndexedDB`.
   * **Поиск в реальном времени:** Мгновенный поиск по инвесторам, кошелькам и стартапам.
   * **Фильтрация по чеку:** Все, Крупные (> $100k), Средние ($30k - $100k), Ангельские (< $30k).
   * **Экспорт базы данных в JSON:** Выгрузка актуального реестра синдиката в один клик.
   * **Сводная статистика:** Общий капитал ($534k+), средний чек, количество синдикатов.

4. **Интеграция Кошельков & Депозиты TRON:**
   * **Официальный реквизит синдиката:** `TVKNb8MWNfxue3dQJxKB9oXT5h9Y88PYb5` (Сеть TRON: USDT-TRC20 / TRX).
   * Динамический QR-код для моментального сканирования мобильными кошельками.
   * Поддержка **TronLink Extension**, **MetaMask**, **Phantom** и институциональных ключей.
